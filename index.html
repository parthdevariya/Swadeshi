        Recognition service

        How to get a free Gemini key (2 minutes)
        1. Open aistudio.google.com/apikey and sign in with any Google account.
        2. Tap Create API key. If asked, choose Create API key in new project.
        3. Copy the key (it starts with AIza), paste it above, tap Test, then Save.

        Cost: free — no credit card. The free tier has per-minute and per-day limits that are plenty for personal shopping.

        Privacy: on the free tier Google may use what you send to improve its products. Only scan product packaging.

        Protect your key (recommended): in Google Cloud Console → Credentials, open the key and set Application restrictions → Websites to , and API restrictions to Generative Language API. Then a copied key is useless anywhere else.

        Advanced: model

        Default gemini-flash-latest always points to Google’s current fast model. Change only if Google retires it.

        How to get a Cloud Vision key
        1. Open Google Cloud Console, sign in and create a project (any name).
        2. Open Billing and link a billing account. Google requires this even for the free tier.
        3. Enable the Cloud Vision API for the project.
        4. Go to Credentials → Create credentials → API key, copy it, paste it above, tap Test, then Save.
        5. Restrict the key: Websites → , API restrictions → Cloud Vision API.

        Cost: the first 1,000 units of each feature per month are free. Each scan uses logo + web + text detection, so about 330 free scans a month. Set a budget alert (e.g. ₹100) to be safe.

        Free & private: text is read on your phone; photos go to Google only if you turn on photo recognition in ⚙️ Settings. Product and brand details come from Open Food Facts, Wikidata and Wikipedia. Ownership changes over time — always check “Country of Origin” on the pack.
